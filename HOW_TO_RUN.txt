============================================================
  이로치 타이쿤 (Shiny Tycoon) 실행 방법
  - Visual Studio + raylib 설정 순서
============================================================

[0] 준비물
------------------------------------------------------------
1. Visual Studio (2022 이상)
   - 설치할 때 "C++를 사용한 데스크톱 개발"을 반드시 체크
2. 이 저장소 (ShinyTycoon 폴더)
   - C:\ShinyTycoon 에 두는 것을 추천
   - 폴더 구조(common / console / gui / images)를 바꾸면 안 됨
     (.cpp 파일이 ../common/ 경로로 헤더를 불러오기 때문)
3. raylib (GUI판만 필요, 콘솔판은 필요 없음)


============================================================
[1] 콘솔판 실행 (raylib 필요 없음)
============================================================
1. Visual Studio -> 새 프로젝트 만들기 -> "빈 프로젝트(C++)"
2. 오른쪽 솔루션 탐색기에서 "소스 파일" 우클릭
   -> 추가 -> 기존 항목 -> console\main_console.cpp 선택
3. 프로젝트 이름(솔루션 탐색기 두 번째 줄) 우클릭 -> 속성
   -> C/C++ -> 명령줄 -> 추가 옵션에  /utf-8  입력 -> 확인
4. Ctrl + F5 로 실행


============================================================
[2] raylib 받기 (GUI판용)
============================================================
1. https://github.com/raysan5/raylib/releases 접속
2. 최신 버전의 Assets 에서 이름에 "win64_msvc" 가 들어간 zip 다운로드
   (예: raylib-6.2_win64_msvc16.zip)
3. 압축을 풀고, 안에 있는 include 폴더와 lib 폴더를
   C:\raylib 안으로 옮김

   최종 모양:
     C:\raylib\include\raylib.h   <- 이 파일이 있어야 함
     C:\raylib\lib\raylib.lib     <- 이 파일이 있어야 함

   주의) C:\raylib\raylib-6.2_win64_msvc16\include 처럼
         폴더가 한 겹 더 들어가면 안 됨


============================================================
[3] GUI판 프로젝트 만들기
============================================================
1. Visual Studio -> 새 프로젝트 만들기 -> "빈 프로젝트(C++)"
   (콘솔판과는 다른 프로젝트로 만들 것)
2. 솔루션 탐색기 "소스 파일" 우클릭
   -> 추가 -> 기존 항목 -> gui\main_gui.cpp 선택
   ※ main_console.cpp 는 넣지 말 것 (main()이 두 개가 되어 충돌)
3. 위쪽 도구 모음(초록색 ▶ 실행 버튼 왼쪽)의 드롭다운 두 개를
     [ Release ]  [ x64 ]
   로 바꿈
   (칸이 안 보이면: 빌드 메뉴 -> 구성 관리자 에서 바꿔도 됨)


============================================================
[4] GUI판 프로젝트 속성 설정
============================================================
1. 솔루션 탐색기에서 "프로젝트 이름"(두 번째 줄, ++ 아이콘)을 우클릭 -> 속성
   ※ main_gui.cpp 파일이나 "소스 파일" 폴더를 우클릭하면 안 됨
     (그러면 "선택 영역에 대한 속성 페이지가 없습니다" 또는
      파일 하나짜리 속성 창이 뜸)
   ※ 제대로 열리면 왼쪽 목록에 "링커" 항목이 보임

2. 창 맨 위가  구성: Release / 플랫폼: x64  인지 확인

3. 아래 4가지를 입력
   (왼쪽 목록의 ▷ 를 눌러 펼친 뒤, 오른쪽 칸을 클릭해서 입력)

   (1) C/C++ -> 일반 -> 추가 포함 디렉터리
         C:\raylib\include

   (2) C/C++ -> 명령줄 -> 추가 옵션 (아래쪽 큰 칸)
         /utf-8

   (3) 링커 -> 일반 -> 추가 라이브러리 디렉터리
         C:\raylib\lib

   (4) 링커 -> 입력 -> 추가 종속성 (원래 있던 내용의 "맨 앞"에 붙여넣기)
         raylib.lib;opengl32.lib;gdi32.lib;winmm.lib;user32.lib;shell32.lib;

       결과 예시:
         raylib.lib;opengl32.lib;gdi32.lib;winmm.lib;user32.lib;shell32.lib;%(AdditionalDependencies)

4. 적용 -> 확인
5. Ctrl + F5 로 실행
   (처음 1~2초 "Loading..." 은 한글 글꼴을 준비하는 시간이라 정상)


============================================================
[5] (선택) 게임 창 뒤에 뜨는 검은 콘솔 창 없애기
============================================================
프로젝트 속성에서
  - 링커 -> 시스템 -> 하위 시스템 :  창(/SUBSYSTEM:WINDOWS)
  - 링커 -> 고급   -> 진입점      :  mainCRTStartup


============================================================
[6] 자주 나는 문제
============================================================
- "raylib.h 를 열 수 없습니다"
    -> 추가 포함 디렉터리 경로 확인
    -> 속성을 Debug 구성에 입력하지 않았는지 확인 (Release / x64 여야 함)

- LNK2019, LNK1104 (링크 오류)
    -> 추가 라이브러리 디렉터리, 추가 종속성 확인
    -> 플랫폼이 x64 인지 확인

- objidl.h 에서 "'byte': 모호한 기호입니다" 오류
    -> main_console.cpp 에서 #include <windows.h> 가 맨 위에 있어야 함
    -> 한 프로젝트에 main_console.cpp 와 main_gui.cpp 를 같이 넣지 말 것

- 한글이 □ 로 나옴 (GUI판)
    -> C:\Windows\Fonts\malgun.ttf 가 있는지 확인
    -> 다른 글꼴을 쓰려면 .ttf 파일을 font.ttf 이름으로 실행 폴더에 두기

- 포켓몬 대신 동그란 도형 캐릭터가 나옴
    -> images 폴더를 찾지 못한 것. ShinyTycoon\images 에
       이름_normal.png / 이름_shiny.png 이미지가 있어야 함
       (저작권 문제로 저장소에 이미지를 넣지 않았다면 이게 정상 동작)


============================================================
[7] 기타
============================================================
- 진행 상황은 실행 폴더(Visual Studio로 실행하면 프로젝트 폴더)의
  save.txt 에 자동 저장됨. 처음부터 다시 하려면 save.txt 삭제.
- 다른 컴퓨터로 옮길 때 Visual Studio 프로젝트 폴더(.sln, .vcxproj)도
  같이 옮기고, ShinyTycoon 과 raylib 을 같은 경로(C:\ShinyTycoon,
  C:\raylib)에 두면 위 설정을 다시 하지 않아도 됨.
