# 이로치 타이쿤 (Shiny Tycoon)

## 폴더 구조

```
ShinyTycoon/
├─ common/              ← 게임 규칙 (콘솔판·GUI판이 함께 사용)
│   ├─ Player.h         플레이어 상태, operator<<
│   ├─ Upgrade.h        Upgrade(부모) + 세대 업그레이드 / 빛나는 부적 / GP 업그레이드(자식)
│   ├─ Shop.h           Upgrade* 관리, Rule of Three (소멸자·복사 생성자·대입 연산자)
│   ├─ Legendary.h      전설 포켓몬 한 마리 (이름, 이미지 이름, 수집 여부)
│   ├─ Worker.h         Worker(부모) + 반바지 꼬마 / 엘리트 트레이너 / 베테랑 트레이너(자식)
│   ├─ WorkerManager.h  Worker* 관리 (알바 고용소), Rule of Three
│   └─ GameCore.h       도감·사냥 목표, 뽑기, 티켓, 업그레이드 구매, 저장/불러오기
├─ console/
│   └─ main_console.cpp 콘솔판 (입력/출력만 담당)
├─ gui/
│   ├─ main_gui.cpp     raylib GUI판 (화면 그리기/마우스·키보드 입력만 담당)
│   └─ Backgrounds.h    전설별 사냥 배경 (도형으로 직접 그림, 23종)
└─ images/              전설 포켓몬 이미지 (이름_normal.png / 이름_shiny.png, 24마리)
```

`.cpp` 파일들은 `../common/...` 경로로 헤더를 불러오므로 **폴더 구조를 그대로 유지**해야 합니다.
GUI판은 `images` 폴더를 자동으로 찾습니다(소스 파일 위치 기준 `../images/`). 못 찾으면 기본 도형 캐릭터로 표시됩니다.

## 게임 흐름

1. 전설 선택 화면(도감)에서 사냥할 전설을 고릅니다. 미수집은 어둡게, 수집 완료는 이로치로 밝게 표시됩니다.
2. 뽑기로 GP를 모으고 업그레이드를 사서 확률을 올립니다.
3. 이로치가 나오면 그 전설을 수집하고, **수집 보상으로 뽑기당 GP +2**를 받습니다.
4. GP와 업그레이드는 다음 전설로 넘어가도 유지됩니다.
5. 24마리를 모두 모으면 게임 클리어입니다.

## 알바

| 알바 | 기본 가격 | 속도 |
|---|---|---|
| 반바지 꼬마 | 200 GP | 3초에 1회 |
| 엘리트 트레이너 | 2,000 GP | 1초에 1회 |
| 베테랑 트레이너 | 15,000 GP | 1초에 3회 |

- 종류별 최대 10명. 고용할수록 가격이 올라갑니다. (기본 가격 × (1 + 고용 수 × 0.5))
- 알바는 지금 사냥 중인 전설을 대신 뽑고, GP도 얻습니다. 이로치를 잡으면 그대로 수집됩니다.
- 사냥 중인 전설이 없으면(선택 화면) 알바는 쉽니다.
- 콘솔판은 메뉴를 고를 때마다 지난 시간만큼 한꺼번에 정산합니다.
- 수치 조정 위치 : `Worker.h`의 각 자식 클래스 (가격, getInterval)

## 저장

- 진행 상황은 **실행 폴더의 `save.txt`** 에 자동 저장됩니다.
  (Visual Studio에서 Ctrl+F5로 실행하면 **프로젝트 폴더**에 생깁니다)
- 콘솔판과 GUI판은 프로젝트 폴더가 다르면 저장 파일도 따로 생깁니다.
- 처음부터 다시 하려면 `save.txt`를 지우면 됩니다.
- 수치 조정 위치 : `GameCore.h`의 `COLLECT_BONUS_GP`(수집 보상), `setupUpgrades`(업그레이드 가격), 생성자의 티켓 가격

## 1. 콘솔판 실행 (Visual Studio)

1. 새 프로젝트 → **빈 프로젝트(C++)**
2. 솔루션 탐색기에서 **소스 파일** 우클릭 → 추가 → **기존 항목** → `console/main_console.cpp` 선택
3. 프로젝트 속성 → C/C++ → 명령줄 → 추가 옵션에 `/utf-8` 입력 (한글 깨짐 방지)
4. 실행 (Ctrl + F5)

---

## 2. GUI판 실행 (Visual Studio + raylib)

### 2-1. raylib 내려받기

1. https://github.com/raysan5/raylib/releases 에서 최신 버전의 **`win64_msvc`가 들어간 zip** 파일을 내려받습니다.
   (예: `raylib-6.2_win64_msvc16.zip` 같은 이름)
2. 압축을 풀어 `C:\raylib` 같은 곳에 둡니다. 안에 `include` 폴더와 `lib` 폴더가 있으면 됩니다.

### 2-2. 프로젝트 만들기

1. 새 프로젝트 → **빈 프로젝트(C++)** (콘솔판과 다른 프로젝트로 만듭니다)
2. **소스 파일** 우클릭 → 추가 → 기존 항목 → `gui/main_gui.cpp` 선택
3. 상단 구성을 **Release / x64** 로 바꿉니다. (raylib 배포판이 Release 기준으로 빌드되어 있습니다)

### 2-3. 프로젝트 속성 설정 (구성: Release, 플랫폼: x64)

| 위치 | 값 |
|---|---|
| C/C++ → 일반 → 추가 포함 디렉터리 | `C:\raylib\include` |
| C/C++ → 명령줄 → 추가 옵션 | `/utf-8` |
| 링커 → 일반 → 추가 라이브러리 디렉터리 | `C:\raylib\lib` |
| 링커 → 입력 → 추가 종속성 (앞에 추가) | `raylib.lib;opengl32.lib;gdi32.lib;winmm.lib;user32.lib;shell32.lib;` |

4. 실행 (Ctrl + F5)

### (선택) 뒤에 뜨는 검은 콘솔 창 없애기

| 위치 | 값 |
|---|---|
| 링커 → 시스템 → 하위 시스템 | `창(/SUBSYSTEM:WINDOWS)` |
| 링커 → 고급 → 진입점 | `mainCRTStartup` |

### 자주 나는 문제

- **`raylib.h`를 찾을 수 없음** → 추가 포함 디렉터리 경로, 그리고 구성이 Release/x64인지 확인
- **LNK2019 (확인할 수 없는 외부 기호)** → 추가 종속성의 `.lib` 목록 확인, x64인지 확인
- **한글이 네모(□)로 나옴** → `C:\Windows\Fonts\malgun.ttf`가 있는지 확인.
  다른 글꼴을 쓰고 싶으면 `.ttf` 파일을 `font.ttf`라는 이름으로 실행 파일 옆(또는 프로젝트 폴더)에 두면 그 글꼴을 먼저 사용합니다.
- **실행하자마자 1~2초 멈춤** → 한글 11,172자를 글꼴 텍스처로 만드는 시간이라 정상입니다.

## GUI 조작법

- **뽑기 버튼 클릭 / Space 키** : 뽑기 1회 (GP 획득)
- **누르고 있기** : 자동으로 계속 뽑기 (1초에 약 14회)
- **오른쪽 상점** : 업그레이드 구매, 연속 뽑기 티켓 구매 (연속 뽑기는 GP 획득 없음)
- **ESC / 창 닫기** : 종료
